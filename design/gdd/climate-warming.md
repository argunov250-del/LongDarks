# Потепление климата (шаг 15)

Статус: черновик на проверку дизайнера, реализовано в `src/climate/` (`ClimateSystem`, `ClimateDefs`, `ClimateBirds`). Все числа — плейсхолдеры, живут в `ClimateDefs`. Опирается на хук `SeasonSystem.set_duration_minutes` (шаг 13) и температурную кривую `SeasonDefs`.

## 1. Обзор
Климат медленно теплеет год за годом: зима сокращается, весна и лето удлиняются, снег весной тает раньше, прилетают птицы. Потепление ускоряют посаженный (выросший) лес и вспаханная земля. Вырубка леса климат НЕ охлаждает — лишь убирает бонус. Шкалы климата и любого UI нет: игрок видит перемены только в мире. Важные события (первые птицы, вехи потепления) уходят на шину (`first_birds`, `warming_milestone`) для будущей системы надежды.

## 2. Фантазия игрока
Надежда, пришедшая не из окна с цифрами, а из мира: «в этом году снег сошёл раньше, и над рекой — первые птицы». Игрок своими руками (сажает лес, пашет) приближает потепление, но видит последствия только глазами. Опора — столп «выживание без подсказок».

## 3. Подробные правила
- Индекс потепления `W` (°C) растёт в конце КАЖДОГО сезона на четверть годового прироста (с событием `season_changed`). Никогда не уменьшается. Предел `MAX_WARMING`.
- Годовой прирост = `BASE_WARMING_PER_YEAR * (1 + бонус)`. Бонус считается по существующему сейчас посаженному/выросшему лесу и вспаханной земле (на момент конца сезона). Природный лес со старта карты бонуса не даёт.
- Вырубка посаженного леса уменьшает счётчик клеток (бонус падает до нуля, не ниже); накопленное `W` остаётся.
- Влияние на `SeasonSystem`: `climate_temp_offset = W * TEMP_PER_WARMING` (ко всем сезонам, и в `base_temp`, и в `outdoor_temp`); длительности сезонов через `set_duration_minutes`; `climate_warm_fraction = W / MAX_WARMING` — сдвиг таяния снега.
- Событие `first_birds` ({year, warming}) один раз в ПЕРВУЮ весну игры, независимо от потепления. Событие `warming_milestone` ({level, warming, year}) один раз на каждую веху из `MILESTONES`.
- Птицы: только весной после `first_birds`. Число от `BIRDS_MIN` до `BIRDS_MAX` по `W/MAX_WARMING`. Стаи до 8 птиц летят дугами к точке рядом с камерой, часть садится на деревья, сидит 4-9 с, взлетает. Прилетают в первые 10% весны, улетают в последние 8%. Один MultiMesh, взмах крыльев в шейдере.
- API для шагов 16-17: `register_planted_forest_cells(n)` (n может быть отрицательным при вырубке), `set_planted_forest_cells(n)`, `set_plowed_cells(n)`, либо колбэки `set_planted_provider(Callable)` / `set_plowed_provider(Callable)`.

## 4. Формулы
- `bonus = min(FOREST_BONUS_MAX, planted * FOREST_BONUS_PER_CELL) + min(PLOW_BONUS_MAX, plowed * PLOW_BONUS_PER_CELL)`
- `dW_season = BASE_WARMING_PER_YEAR * (1 + bonus) / 4`; `W = min(MAX_WARMING, W + dW_season)`
- `f = W / MAX_WARMING`; `freed = winter0 * (1 - WINTER_MIN_FRACTION) * f`
- `winter = winter0 - freed`; `spring = spring0 + freed * SPRING_SHARE`; `summer = summer0 + freed * (1 - SPRING_SHARE)`; осень без изменений. Сумма сезонов постоянна.
- Таяние: `melt_from = lerp(0.05, 0.0, f)`, `melt_to = lerp(0.6, 0.3, f)` (доли весны).
- `birds = round(lerp(BIRDS_MIN, BIRDS_MAX, f))`

Пример (без бонусов): 0.6 °C/год; первые птицы в первую весну; зима 30 -> 18 мин за ~13 лет. С полным бонусом (x3.5): ~4 года. Год = 100 мин при 1x.

## 5. Граничные случаи
- Потепление не падает: вырубка, снос, отрицательные счётчики (зажимаются в 0).
- Бонус ограничен потолками; `W` ограничен `MAX_WARMING`, зима не короче 60% начальной.
- Несколько вех в один шаг: события эмитятся по одному, каждое один раз; флаги сохраняются (после загрузки не повторяются).
- Смена длительностей в начале сезона: `set_duration_minutes` сохраняет долю текущего сезона, сезон не перескакивает.
- Нет посадки и вспашки (шаги 16-17): бонус 0, работает только база.
- Нет подходящего леса для посадки птиц: стая просто пролетает.

## 6. Зависимости
`SeasonSystem` (хук длительностей, `climate_temp_offset`, `climate_warm_fraction`, `snow_cover`), `EventBus`, `WorldMap`/`Deposits` (деревья для посадки птиц), сохранение (`climate`). Будущие: посадка леса (16), вспашка (17), надежда (потребность) — подписка на `first_birds` / `warming_milestone`.

## 7. Ручки настройки (`ClimateDefs`)
`BASE_WARMING_PER_YEAR`, `FOREST_BONUS_PER_CELL/MAX`, `PLOW_BONUS_PER_CELL/MAX`, `MAX_WARMING`, `TEMP_PER_WARMING`, `WINTER_MIN_FRACTION`, `SPRING_SHARE`, `MILESTONES`, `BIRDS_MIN/MAX`, `BIRD_*` (визуал). Таяние: `SeasonDefs.SNOW_SPRING_MELT_*_WARM`.

## 8. Критерии приёмки
Тесты `tests/climate/`: базовое потепление по годам; зима короче, но не ниже минимума; длина года постоянна; посадка/вспашка ускоряют; вырубка убирает бонус, но не охлаждает; вехи один раз; птицы только весной после первых птиц; снег тает раньше; нет шкалы климата в UI; сохранение/загрузка. Скриншот: `production/qa/evidence/climate_birds.png`.

## Решения (утверждено дизайнером)
1. Базовое потепление 0.6 °C/год (зима минимума за ~13 лет без бонусов).
2. Бонус: 0.004 за клетку посаженного леса (потолок +1.5), 0.01 за вспаханную клетку (потолок +1.0); итог до x3.5.
3. Зима не короче 60% начальной (30 -> 18 мин); предел потепления 8 °C.
4. Освободившиеся минуты делятся поровну между весной и летом; год постоянен (100 мин).
5. Температурная добавка равна потеплению (до +8 °C ко всем сезонам, 1:1; утверждено).
6. Снег тает раньше: окончание таяния с 60% до 30% весны, начало с 5% до 0%.
7. Первые птицы в первую весну игры; вехи 1, 2, 4, 6, 8 °C; птиц 8..48 (стаи по 8).
8. Потепление накапливается по четверти в конце каждого сезона (а не раз в год).
