# Цепочки топлива, переделки и доработки техники (шаг 20)

## 1. Обзор
Цепочки простые в один шаг, кроме топлива (2-3 шага): биодизель (рапс -> масло -> биодизель), спирт (зерно или картофель), дрова для газогенератора, биогаз (навоз + отходы). У каждой машины свой тип двигателя; в мастерской её переделывают под биотопливо или газогенератор и ставят доработки. Реализация: `src/fuel/*`, `vehicle_system.gd`, `recipes.gd`, `building_defs.gd`. Тесты `tests/fuel/`.

## 2. Образ игрока
Брошенная развалина доживает на остатке старого топлива; настоящая жизнь начинается, когда посёлок сам делает топливо и машина ездит на нём.

## 3. Правила
- **Здания (вкладка «Производство»)**: маслобойня (есть), биодизельная установка, винокурня, биогазовая установка.
- **Навоз**: корова в сарае даёт 1 навоз за период (склад). **Отходы**: испорченная еда (на складах, в домах, столовых) становится отходами, если есть место.
- **Двигатель**: дизельный (грузовик, внедорожник, трактор, комбайн, экскаватор, бульдозер, кран) или бензиновый (пикап, вездеход, снегоход). Найденные машины стоят на остатке старого топлива (литры в баке).
- **Топливо по двигателю**: дизель без переделки принимает биодизель; бензиновый без переделки поселковое топливо не принимает. Переделка «Биотопливо» — биодизель и спирт. «Газогенератор» — только дрова: бак превращается в бункер (40%), скорость x0.7, расход x1.5; остаток старого топлива сливается. Неподходящее топливо машина не принимает.
- **Заправка**: физическая. Бак ниже 30% — рейс к ближайшему складу с подходящим топливом, 8 с заправки (газогенератор грузят дровами так же, поэтому остановки частые). Пустую машину докатывают до склада (канистр нет).
- **Переделки и доработки** — задания очереди мастерской (шаги по 10 с работы механика, цена за шаг), навык механика ускоряет. Сохранение посреди работы хранит прогресс.
- **Доработки**: цепи (скольжение x0.55 в грязи/снегу), утепление (отказ запуска x0.5, прогрев x0.7, разряд аккумулятора x0.5, остывание вдвое медленнее), фары (ночью скорость x0.95 вместо x0.7, аварии x1.05 вместо x1.4).
- **UI**: карточка машины показывает двигатель, переделку, доработки; кнопки «Переделать…» и «Доработать…»; топливо в литрах.

## 4. Формулы
Заправка: единиц = ceil(свободные л / л на единицу). Расход = км x л/км x множитель газогенератора x (1 + 0.5 x загрузка).

## 5. Крайние случаи
Нет мастерской — переделка не ставится. Вторая переделка/повтор доработки/второе задание — отказ. Удаление машины снимает задание. Склад опустел по дороге — рейс срывается. Нет места для отходов — они не создаются. Старые сохранения: поля по умолчанию.

## 8. Критерии приёмки
`tests/fuel/test_fuel.gd`: каждая цепочка по шагам; отказ неверного топлива; переделка открывает топливо; газогенератор на дровах медленнее; рейс на заправку; цепи, утепление, фары; сохранение посреди переделки.

## Решения для проверки — утверждено дизайнером
1. Биодизель работает в дизелях без переделки; бензиновым нужна переделка.
2. Остаток старого топлива просто сгорает; газогенератор его сливает.
3. Пустую машину докатывают до склада вручную, канистр нет.
4. Топливный склад не строим: заправка на обычных складах.
5. Биогаз пока только копится (потребитель — отопление/электричество, позже).
6. Переделки идут через очередь ремонта мастерской.
7. Все числа — плейсхолдеры.
