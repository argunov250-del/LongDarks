# Карьера — каркас (шаг 26)

## 1. Обзор
Короткий режим: 4 главы, в каждой несколько целей; после финала главы 4 — титры и возврат в меню. Сюжет добавляет дизайнер: сейчас в `data/career/chapters.json` только нейтральные тексты «ЗАГЛУШКА — сюжет добавит дизайнер».

## 2. Образ для игрока
Видит компактный список целей текущей главы, перед главой и после неё — панель с текстом, в конце — титры.

## 3. Правила
- Новая игра -> Карьера -> сложность -> старт. Сложность работает как в песочнице.
- Фазы главы: `intro` (панель, игра на паузе) -> `active` -> `outro` (панель, пауза) -> следующая глава. Пустой `intro`/`outro` панель пропускает. После `outro` главы 4 — `credits` (пауза), затем «В главное меню».
- Цели главы выполняются в любом порядке; выполненная цель фиксируется. Глава завершается, когда выполнены все цели.
- События считаются с начала главы и только в фазе `active`.
- Вне режима «Карьера» система неактивна и ничего не меняет.
- Сохраняется: active, номер главы, фаза, выполненные цели, счётчики.

## 4. Формат данных
`data/career/chapters.json`: `chapters[]` -> `id`, `title`, `intro`, `outro` (необязательные), `start_state` (необязательно: `resources {id: n}`, `season`, `season_progress`), `objectives[]` -> `id` (уникален во всём файле), `type`, `text`, `params`. Блок `credits`: `title`, `thanks`, `speed`, `entries[{role,name}]`.

| type | params | как считается |
|---|---|---|
| build | building, count | событие завершения здания этого типа |
| harvest | resource ("" — любой), count | собранный с полей урожай (событие `crop_harvested`) |
| repair | count, prefix? | завершённые ремонты в мастерской (`repair_done`) |
| event | topic, count, field?, value? | любой топик шины (+1 за событие) |
| population | count | жителей не меньше |
| survive_until | season, year | наступил сезон года (spring..winter) |
| relation | min, neighbour? | лучшее (или указанного соседа) отношение >= min |
| resource | resource, count | запас на складах >= count |

Пример:
```json
{"id": "ch1_well", "type": "build", "text": "Построить колодец", "params": {"building": "well", "count": 1}}
```
Битые главы/цели отбрасываются и пишутся в предупреждения (`push_warning`), игра не падает.

## 5. Как добавить сюжет
Правьте только `title`, `intro`, `outro`, `text` целей и `credits` в JSON; код не трогать. Новые цели — новые объекты в `objectives`. Новое условие по событию — тип `event` с нужным топиком.

## 6. Крайние случаи
Нет файла/плохой JSON — карьера неактивна, ошибки в `errors`. Загрузка с неверным номером главы — значение ограничивается. Панель при загрузке сохранения показывается заново.

## 7. Ручки
`CareerSystem.POLL_INTERVAL`, `credits.speed`, все цели и числа — в JSON.

## 8. Приёмка
Данные грузятся и валидируются; каждый тип условия срабатывает; порядок глав; главa 4 -> титры; сохранение посреди главы; песочница не затронута; скриншоты `career_tracker.png`, `career_credits.png`. Тесты: `tests/career/`.

## Решения для проверки
1. Цели главы выполняются в любом порядке и фиксируются навсегда.
2. Счётчики событий сбрасываются в начале главы.
3. Игра на паузе во время панелей и титров.
4. `repair` считает любой ремонт в мастерской (не только машины) — уточнить через `prefix`.
5. Цели-заглушки (число, ресурсы) — плейсхолдеры баланса.
